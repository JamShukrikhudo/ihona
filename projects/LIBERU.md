# Liberu application composition

This repository composes the Liberu boilerplate foundation with the
project-relevant Real Estate core, API, Filament, and Livewire modules.

Foundation packages remain reusable and presentation-neutral. Real Estate
packages are selected one-to-one across the four implementation indexes.
Source repositories use the module- GitHub prefix; Composer and Packagist
package names intentionally omit it.

Deferred frontend indexes and implementations are not part of this run.
