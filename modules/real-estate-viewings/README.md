# Real Estate Viewings

Availability returns weekday 09:00–17:00 ISO-8601 slots, excludes overlapping
requested or confirmed bookings, and booking rechecks stale slots before
creation.

Team-scoped viewing availability, booking, confirmation, access, accompaniment, reminders, feedback, and no-show tracking. Composer is unprefixed; GitHub source uses `module-real-estate-viewings`.
