# Real Estate Properties Livewire

Livewire 4 adapter for authorized, team-scoped property search. It provides a
compact list, detail, and advanced search components with bounded price, room,
area, type, country, energy, and featured filters. Public state is validated and
the components delegate data access through the core query boundary. The detail
component exposes dated disclosure facts and emits a viewing-request event so a
host application can compose the dedicated viewings booking component.
