# Feature module index

Feature specifications are framework-neutral and map one-to-one to core
packages and their optional API, Filament, and Livewire adapters.

The application currently selects the Real Estate scope. Its authoritative
product plan is documented in projects/real-estate/REAL-ESTATE.md.

Deferred React, Vue, Nuxt, React Native, and Flutter indexes are intentionally
not generated by this refactor.
